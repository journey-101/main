## 디렉토리 목적

이 디렉토리는 현재 코드베이스가 노출하거나 사용하는 데이터 계약을 정리한다. 작업 계획이나 변경 이력보다는 현재 동작 기준의 참조 문서를 유지하는 것이 목적이다.

## 작성 방법

- DB 구조는 `db.md`에 Mermaid ER 다이어그램과 테이블 설명으로 작성한다.
- API 계약은 `api/` 아래에 도메인별 문서로 분리한다.
- 문서 상단에는 변경일과 변경 브랜치를 기록한다.
- 코드 블록, 경로, 필드명, enum 값은 실제 코드와 같은 표기를 사용한다.
- 설명 문장은 한국어로 작성한다.
