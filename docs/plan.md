# MoSCoW Plan

## Must Have

MVP에서 반드시 구현해야 하는 기능이다.

| 기능                  | 설명                                                                       |
| --------------------- | -------------------------------------------------------------------------- |
| 관광 준비도 진단      | 외출 경험, 혼잡도 민감도, 이동 부담 등을 입력받는다.                       |
| 위치 기반 관광지 조회 | 현재 위치 기준 주변 관광지를 조회한다.                                     |
| 부천시 관광지 추천    | MVP 지역을 부천시로 제한한다.                                              |
| 관광 난이도 계산      | 이동 거리, 혼잡도, 체류 시간, 귀가 용이성 등을 기준으로 난이도를 계산한다. |
| 단계형 코스 추천      | 산책, 짧은 체류, 실내 문화공간 등 낮은 난이도부터 추천한다.                |
| 절차 정보 제공        | 준비물, 예상 비용, 예약 필요 여부를 제공한다.                              |
| 관광 중 피드백        | 사람이 많음, 이동 부담, 괜찮았음 등의 피드백을 받는다.                     |
| 오늘은 여기까지       | 중간 중단을 실패가 아닌 관광 시도로 기록한다.                              |
| 귀가 경로 제공        | 현재 위치 기준 귀가 방법을 제공한다.                                       |

## Should Have

핵심 기능은 아니지만 서비스 완성도를 높이는 기능이다.

| 기능               | 설명                                                     |
| ------------------ | -------------------------------------------------------- |
| 혼자 가기 적합도   | 혼자 방문해도 어색하지 않은 장소를 표시한다.             |
| 관광지 집중률 반영 | 혼잡도 데이터를 난이도 계산에 반영한다.                  |
| 사용자 프로필 저장 | 사용자별 부담 요소와 선호 정보를 저장한다.               |
| 대체 코스 추천     | 사용자가 부담을 느낄 경우 더 쉬운 코스를 제안한다.       |
| 코스 요약 카드     | 이동 시간, 체류 시간, 비용, 귀가 방법을 한눈에 보여준다. |

## Could Have

MVP 검증 이후 고려할 기능이다.

| 기능               | 설명                                       |
| ------------------ | ------------------------------------------ |
| AI 추천 이유 설명  | 왜 이 장소가 적합한지 자연어로 설명한다.   |
| 감정 기반 추천     | 현재 기분에 따라 코스를 조정한다.          |
| 성장 그래프        | 사용자의 관광 적응도를 시각화한다.         |
| 코스 공유          | 추천 코스를 외부에 공유한다.               |
| 출발 전 체크리스트 | 교통카드, 충전기, 예약 확인 등을 체크한다. |
| 다지역 확장        | 부천 외 지역으로 서비스를 확장한다.        |

## Won't Have

초기 버전에서 제외할 기능이다.

| 기능                 | 제외 이유                                         |
| -------------------- | ------------------------------------------------- |
| 숙박 예약            | 초기 서비스는 생활형 관광에 집중한다.             |
| 항공/기차 예약       | 장거리 여행보다 낮은 난이도 관광 경험이 우선이다. |
| 복잡한 다일정 플래너 | MVP에서는 짧고 가벼운 코스 추천이 핵심이다.       |
| SNS 피드             | 과시형 기록보다 실행 지원이 핵심이다.             |
| 실시간 채팅          | 운영 부담과 안전 관리 비용이 크다.                |
| 결제 기능            | 초기 검증 범위에서는 필요성이 낮다.               |
| 전국 단위 추천       | 초기에는 부천시 기반으로 추천 로직을 검증한다.    |

## MVP 범위

### 포함

- 관광 준비도 진단
- 부천시 관광지 조회
- 관광 난이도 계산
- 단계형 코스 추천
- 절차 정보 제공
- 관광 중 피드백
- 오늘은 여기까지
- 귀가 경로 제공

### 제외

- 숙박 예약
- 결제
- SNS 피드
- 실시간 채팅
- 전국 단위 추천
- 복잡한 다일정 여행 플래너
