## 디렉토리 목적

이 디렉토리는 프런트 담당자가 주차별 backend API 작업 내용을 빠르게 확인할 수 있도록 정리한다. 각 문서는 해당 주차에 사용할 API 목록과 유저/테스트 플로우를 함께 설명한다.

## 작성 방법

- 파일명은 주차 기준으로 작성한다. 예: `w1.md`, `w2.md`
- 문서 상단에는 변경일과 변경 브랜치를 기록한다.
- 해당 주차에 추가되거나 확인해야 할 API 목록을 먼저 요약한다.
- 프런트에서 따라갈 유저 플로우와 검증용 테스트 플로우를 단계별로 작성한다.
- 요청/응답 예시는 실제 API 계약과 동일하게 작성하고, 상세 계약은 `docs/schema/api/` 문서로 연결한다.
- 설명 문장은 한국어로 작성하고, 코드 블록과 API 경로/필드명은 원문 표기를 유지한다.
