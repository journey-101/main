# Product Spec

## 1. 서비스 정의

CoTraveler는 여행 의지는 있지만 실행 과정에서 부담을 느끼는 초보 여행자를 위한 단계형 관광 지원 서비스다.

본 서비스는 인기 관광지를 많이 추천하는 것이 아니라,
사용자가 현재 감당 가능한 수준의 관광 경험을 시작할 수 있도록 돕는 것을 목표로 한다.

## 2. 문제 정의

초보 여행자는 관광지 정보 부족보다 실행 과정에서 더 큰 부담을 느낀다.

주요 부담 요소는 다음과 같다.

- 어디서부터 시작해야 할지 모름
- 이동, 환승, 예약, 준비물 확인 부담
- 혼자 방문하는 상황의 어색함
- 혼잡한 공간에 대한 부담
- 중간에 포기하면 실패라고 느끼는 문제

## 3. 설계 의도

핵심 설계 원칙은 다음과 같다.

1. 인기순 추천보다 난이도 기반 추천을 우선한다.
2. 장거리 여행보다 낮은 난이도의 생활형 관광부터 시작한다.
3. 완주보다 시도 자체를 긍정적으로 기록한다.
4. 사용자 피드백을 다음 추천에 반영한다.
5. 언제든 중단하고 귀가할 수 있는 안전장치를 제공한다.

## 4. 핵심 사용자 흐름

1. 사용자가 현재 상태를 입력한다.
2. 서비스가 관광 준비도를 판단한다.
3. 낮은 난이도의 관광 미션을 추천한다.
4. 사용자가 이동, 비용, 준비물, 혼잡도 정보를 확인한다.
5. 관광 중 피드백을 입력한다.
6. 완료하거나 "오늘은 여기까지"를 선택한다.
7. 결과가 사용자 프로필에 반영된다.
8. 다음 추천 난이도가 조정된다.

## 5. 핵심 기능

### 관광 준비도 진단

사용자의 외출 경험, 혼자 이동 부담, 혼잡도 민감도, 선호 체류 시간 등을 입력받는다.

### 난이도 기반 관광 추천

관광지를 단순 인기순으로 추천하지 않고 다음 요소를 기준으로 난이도를 계산한다.

- 이동 거리
- 예상 체류 시간
- 혼잡도
- 귀가 용이성
- 혼자 방문하기 적절한 정도
- 예약 필요 여부
- 예상 비용
- 이전 피드백

### 관광 중 피드백

사용자는 관광 중 다음과 같은 피드백을 남길 수 있다.

- 사람이 너무 많았다
- 이동이 부담스러웠다
- 생각보다 괜찮았다
- 혼자 있어도 어색하지 않았다
- 오늘은 여기까지 하고 싶다

### 오늘은 여기까지

사용자가 중간에 관광을 중단해도 실패로 기록하지 않는다.
해당 경험을 관광 시도로 기록하고, 다음 추천 난이도를 조정한다.

### 귀가 지원

현재 위치 기준으로 귀가 경로, 가까운 지하철역, 버스정류장, 택시 호출 연결 정보를 제공한다.

## 6. 데이터 활용

### 활용 API

- 한국관광공사 위치 기반 관광정보 조회 API
- 한국관광공사 지역 기반 관광정보 조회 API
- 한국관광공사 키워드 검색 조회 API
- 한국관광공사 관광지 집중률 정보 API

### 활용 방식

관광 데이터를 단순 관광지 목록이 아니라 난이도 판단 기준으로 사용한다.

- 위치 기반 정보: 주변 관광지 탐색
- 지역 기반 정보: 부천시 관광 코스 구성
- 키워드 검색: 조용한 곳, 실내, 산책 등 조건 탐색
- 관광지 집중률: 혼잡도 기반 난이도 조정

## 7. 초기 지역

초기 지역은 부천시로 설정한다.

부천시는 서울과 인접해 접근성이 높고, 지하철 중심 이동이 가능하며,
영화, 만화, 공연 등 문화 콘텐츠 기반 관광 자원이 있어 초보 여행자를 위한 단계형 관광 코스를 구성하기 적합하다.
